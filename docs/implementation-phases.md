# TradePath implementation phases

The supplied PRD is product reference material. Its embedded coding-agent prompt is not a separate authorization. The user's oxblood, pearl white and black palette supersedes PRD section 10.

## 1. Foundation and security
Deliver Next.js/TypeScript scaffold, responsive navigation and visual tokens, environment configuration, Nairobi date utilities, reviewed Supabase migrations, email magic-link authentication and onboarding. Protect all private routes and mutations. Validate ownership with two users and anonymous access before enabling cloud writes.

## 2. Daily practice and curriculum
Deliver Today, idempotent local-date sessions, weekday/weekend task templates, six curriculum phases, evidence-derived milestones, session check-ins and justified no-trade decisions. Verify reload persistence, midnight rollover and study-only choices. Phase dates guide practice; elapsed time never passes an evidence gate.

## 3. Rules, risk and journal
Deliver decimal-safe position sizing, deterministic H4H1-v1 evaluator, immutable evaluations, protected trade calculations, journal CRUD, private screenshots and revisions. Verify BUY/SELL orientation, unknown evidence, candle timing, news freshness, daily limits, minimum lots, frozen initial risk and costs. External breaches must remain visible.

## 4. Insights and reflection
Deliver mode-separated analytics, explicit denominators, weekly review, equity-based drawdown, readiness evidence and CSV/JSON export. Verify against hand-calculated fixtures. No trades means insufficient data, not a perfect score. Simulator belongs to Release 3.

## 5. PWA and launch verification
Deliver manifest and raster icons, read-only offline fallback initially, explicit online write requirements, account deletion including storage, accessibility and mobile end-to-end coverage. Add queued writes only after idempotency/conflict handling is verified. Require all AC-01–AC-20 relevant to MVP and verified HTTPS preview before launch; provider simulator scenarios remain release-gated.
